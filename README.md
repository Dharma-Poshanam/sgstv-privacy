# SGS TV privacy policy

The privacy policy for the SGS TV apps (Android TV / Google TV and LG webOS) of
Avadhoota Datta Peetham, Mysuru.

**Published at:** https://dharma-poshanam.github.io/sgstv-privacy/

This is the URL given to Google Play and the LG Content Store. It is a single static page
(`index.html` + `privacy.css`, no scripts) served by GitHub Pages from `main`.

## Changing it

The policy describes what the apps actually do, so it changes with the code in
[Sumvid-Solutions/sgstv](https://github.com/Sumvid-Solutions/sgstv) (private), where the same
page lives at `web/player/privacy.html`. Keep the two in step: change the code, update the
policy and the "Last updated" date in both places, then merge here before the app release that
needs it.
